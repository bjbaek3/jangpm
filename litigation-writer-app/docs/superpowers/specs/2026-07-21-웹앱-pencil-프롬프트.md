# 웹 앱 화면별 Pencil 위임 프롬프트

설계 근거: `2026-07-21-웹앱-배포-design.md` §8.
사용법: 각 화면 프롬프트를 Pencil MCP 세션에 넘길 때 **맨 앞에 아래 공통 블록을
붙여서** 전달한다. 예시 데이터는 골든 케이스(2026_김민재 해고 무효, 가상 사건)를 쓴다.
사건 상세의 입력자료 탭(파일 목록)·리서치 탭(MD 렌더 + 목차)은 표준 패턴이라
별도 목업을 만들지 않는다 — 구현 시 shadcn 기본 컴포넌트로 충분.

---

## 공통 디자인 언어 블록 (모든 프롬프트 서두에 포함)

> 한국 소규모 법률사무소가 쓰는 내부용 송무서면 생성 도구의 웹 UI다. 데스크톱 우선
> (1440px 기준), 한국어 UI. shadcn/ui + Tailwind 문법의 컴포넌트 감성: 카드,
> 테이블, 배지, 탭, 드로어, 모달. 라이트 모드 기본.
> 톤: 차분하고 신뢰감 있는 법률 도구 — 장식 최소, 정보 밀도 중간, 여백 넉넉.
> 색: 중립 회색 베이스 + 프라이머리 남색(#1e3a8a 계열). 빨강은 오직
> "제출 금지"·"확인필요"·검증 FAIL에만. 초록은 승인·PASS. 주황은 "응답 필요"·
> "검수 대기" 등 사용자 액션 대기.
> 타이포: Pretendard, 본문 14px, 제목 18~24px. 표는 행 높이 촘촘하게.
> 공통 셸: 좌측 고정 네비(240px — 로고 "송무서면 생성기", 메뉴: 사건, 설정,
> 하단 사용자 아바타+이름) + 우측 콘텐츠 영역. 로그인 화면만 셸 없음.
> 상태 배지 체계(전 화면 공통): 대기(회색) / 실행중(파랑, 스피너) / 응답 필요(주황,
> 펄스) / 검수 대기(주황) / 제출 금지(빨강) / 완료(초록).

---

## ① 로그인

공통 셸 없이 중앙 카드 1장. 로고와 서비스명 "송무서면 생성기", 부제 "AI 초안 —
변호사 검수 전 제출 금지". 이메일·비밀번호 필드, [로그인] 버튼(프라이머리),
하단 안내문 "계정은 관리자 초대로만 생성됩니다". 오류 상태 변형: 필드 아래 빨간
"이메일 또는 비밀번호가 올바르지 않습니다". 배경은 아주 옅은 회색, 카드 그림자 약하게.

## ② 사건 목록 (홈)

콘텐츠 헤더: 제목 "사건", 우측 [+ 새 사건] 프라이머리 버튼. 그 아래 필터 줄:
상태 멀티셀렉트 칩, 담당자 셀렉트, 검색 인풋.
본문은 테이블: 컬럼 = 사건명 / 담당 / 진행(미니 스테퍼: 사건구성→리서치→서면→검증
4칸 도트, 완료 칸은 채움) / 상태 배지 / 최근 활동(상대시간).
행 예시 5개: "김민재 — 해고 무효 확인" (검수 대기, 주황), "정하윤 — 임대차보증금
반환" (실행중, 파랑 스피너), "박OO — 대여금" (응답 필요, 주황 펄스), "이OO — 손해배상"
(제출 금지, 빨강), "최OO — 공사대금" (완료, 초록).
"응답 필요"·"검수 대기" 행은 좌측 보더 주황 강조 — 변호사의 할 일이 가장 먼저
보여야 한다. 빈 상태 변형: 일러스트 없이 "아직 사건이 없습니다. 새 사건을 등록하세요."

## ③ 새 사건 등록

단일 컬럼 폼 페이지(max-width 720px): 사건명 인풋("예: 2026_김민재 해고 무효"),
담당 변호사 셀렉트, 구분선, "입력 자료" 섹션 — 탭 2개: [텍스트 붙여넣기](큰
textarea, placeholder "상담메모·사건 경위 등을 붙여넣으세요") / [파일 업로드]
(드래그앤드롭 존, 안내 ".md .txt .pdf — 텍스트 레이어 있는 PDF만, 복수 가능",
업로드된 파일 칩 목록 + 삭제 버튼). 하단 [사건 등록] 프라이머리, [취소] 고스트.
도움말 캡션: "등록 후 사건구성 단계를 실행하면 AI가 사건컨텍스트를 만듭니다."

## ④-a 사건 상세 — 기본(개요 탭, 사건구성 실행 전)

헤더: 뒤로가기 ←, 사건명 "김민재 — 해고 무효 확인", 상태 배지 `대기`, 담당 아바타.
그 아래 **파이프라인 스테퍼**(가로 카드): 라운드 셀렉트 "라운드 1 — 소장" +
4단계: ①사건구성 [실행] 버튼 활성 ②리서치 🔒 ③소장 작성 🔒 ④인용검증 🔒.
각 단계는 아이콘+이름+상태 캡션.
탭 바: 개요 | 입력자료 | 사건컨텍스트 | 리서치 | 서면 | 검증보고 (미생성 탭은 비활성).
개요 탭 본문: 좌 2/3 — 최근 활동 타임라인(등록·업로드 이벤트), 우 1/3 — 사건 정보
카드(당사자 요약, 등록일, 입력 파일 2개 목록).

## ④-b 사건 상세 — 실행중 (콘솔 드로어 열림)

④-a와 동일 구조에서: 배지 `실행중`, 스테퍼 ②리서치가 파랑 스피너 "실행 중 — 3분
경과". 우측에서 **실행 콘솔 드로어**(약 420px)가 열림: 헤더 "리서치 실행 중" +
[실행 취소] 아웃라인 버튼(빨간 텍스트), 본문은 접이식 타임라인 항목들 —
"✓ 사건컨텍스트 로드", "✓ 쟁점 1: 해고의 정당성 — 판례 8건 조회", "⟳ 쟁점 2:
임금 지급 — 조문 대조 중…"(스피너). 항목 펼침 상태 하나 포함(회색 모노스페이스
상세 로그 3줄). 드로어 하단 캡션 "korean-law-mcp로 원문 대조 중".

## ④-c 사건 상세 — 체크포인트 (쟁점 승인 카드)

④-b와 동일 구조에서: 배지 `응답 필요`(주황 펄스), 스테퍼 ①사건구성이 주황
"응답 대기". 콘솔 드로어 안에 **체크포인트 카드**(보더 주황): 제목 "쟁점 승인이
필요합니다", 설명 "AI가 도출한 쟁점 후보입니다. 수정·삭제·추가 후 승인하세요."
쟁점 표: 컬럼 = ID/제목/우리 주장/액션(연필·휴지통 아이콘). 행 3개 예시:
"S1 / 해고의 절차적 정당성 / 서면 통지 없이 구두 해고 — 근기법 위반",
"S2 / 해고의 실체적 정당성 / 정당한 이유 없음", "S3 / 미지급 임금 / 2개월분 체불".
[+ 쟁점 추가] 고스트 버튼, 하단 [3개 쟁점 승인하고 계속] 프라이머리.
카드 아래 안내 캡션: "응답 전까지 세션은 일시정지 상태이며 비용이 발생하지 않습니다."

## ④-d 사건 상세 — 검수 대기 (사건컨텍스트 탭 + 게이트 바)

배지 `검수 대기`, 스테퍼 ①사건구성 완료(초록 체크) ②리서치 [실행] 활성화 대기.
사건컨텍스트 탭 활성. 탭 상단에 **검수 게이트 바**(주황 배경 옅게): "사건구성
산출물 검수 — 승인하면 리서치를 진행할 수 있습니다" + [승인하고 다음 단계로]
프라이머리 + [수정 지시…] 아웃라인(클릭 시 텍스트 입력 팝오버).
본문(스크롤): ① 당사자 카드 2장(원고 김민재/피고 ㈜OO — 이름·주소·연락처)
② "사실관계" 표: 일자/내용/근거 컬럼, 행 4개 예시(근거 셀은 "상담메모 §2", "갑2"
같은 회색 모노 칩) ③ 쟁점 카드 3장(승인됨 체크 표시) ④ 청구 요약 카드
⑤ **확인필요 체크리스트** 카드(보더 빨강 옅게): "지연이자 이율", "피고 법인 등기부상
주소", 각 항목에 빨간 점 + "[변호사 확인 필요]" 라벨.

## ④-e 사건 상세 — 제출 금지 (검증보고 탭)

헤더에 빨간 `제출 금지` 배지 추가. 스테퍼 ④인용검증 빨간 X "FAIL 2건".
검증보고 탭 활성, 상단 빨간 경고 배너: "❌ 인용 2건 검증 실패 — 이 서면은 제출
금지 상태입니다. 수정 지시 후 재검증하세요." + [수정 지시…] 버튼.
본문 표: 컬럼 = 인용/유형/대조 결과/비고. 행 예시 6개 — PASS 4개(초록 체크,
"대법원 2019다12345 — 원문 일치"), FAIL 2개(빨간 X, "근로기준법 제27조 — 조문
번호 불일치", "대법원 2020다67890 — 판시사항 발췌 불일치"). FAIL 행은 배경 옅은 빨강.

## ⑤ 사건 상세 — 서면 탭 (버전 히스토리)

배지 `검수 대기`. 서면 탭 활성, 게이트 바 포함(④-d와 동일 패턴, 문구 "소장 초안
검수"). 본문 좌 2/3: 서면 텍스트 미리보기 카드 — "청 구 취 지" 섹션(중앙 정렬
제목, 본문 "1. 피고는 원고에게 금 4,500,000원 및 이에 대하여…"), "청 구 원 인"
섹션 일부. 우 1/3: [DOCX 다운로드] 프라이머리 풀폭 버튼 + "버전" 카드 —
목록 "v3 · 방금 · 수정 지시 반영(현재)", "v2 · 어제 · 검증 FAIL 수정",
"v1 · 2일 전 · 최초 생성", 각 행에 다운로드 아이콘.

## ⑥ 시니어 조언 모달

④ 화면 위 오버레이 모달(max-width 640px). 헤더: "시니어 변호사 송무 조언" +
닫기 X. 헤더 바로 아래 주황 옅은 배너: "⚠ 이 조언은 어디에도 저장되지 않습니다.
닫으면 다시 볼 수 없습니다(재검증 시에만 재생성)." 본문: 번호 목록 3항목의 조언
텍스트(예: "1. 소 제기 전 내용증명으로 임금 지급 최고를 남겨두면 지연손해금
기산점 입증이 깔끔해집니다…"). 하단 [확인하고 닫기] 버튼 하나만.

## ⑦ 설정

탭 3개: 멤버 | 연동 상태 | 사용량.
- **멤버 탭**(기본): 테이블 — 이름/이메일/역할 셀렉트(관리자·멤버)/상태(활성·초대
  대기)/액션. 상단 [멤버 초대] 버튼 → 이메일 입력 인라인 폼. 캡션 "역할 변경과
  초대는 관리자만 가능합니다."
- **연동 상태 탭** 변형: 카드 3장 — "Anthropic API" (초록 점 · 정상, 키 마스킹
  sk-ant-***), "국가법령정보센터 (LAW_OC)" (초록 점 · 정상), "korean-law MCP 래퍼"
  (초록 점 · 헬스체크 통과 · 방금 전). 하단 회색 고지 카드: "실행 세션 데이터는
  Anthropic Managed Agents 서버에 보관됩니다."
- **사용량 탭** 변형: 요약 스탯 3개(이번 달 비용/실행 횟수/평균 단계 비용) +
  사건별 표(사건/실행 수/토큰/비용) + "단계당 비용 상한" 인풋(기본 $5) + 저장.
