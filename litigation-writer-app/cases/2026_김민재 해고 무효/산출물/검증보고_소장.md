## 2. 메커니즘 메모 — `get_law_text`(연혁 MST)와 `legal_analysis`(applicable_law)의 불일치

근로자퇴직급여 보장법 제8조·제9조 핀의 MST(279829, [연혁])에 대해 `get_law_text(mst=279829)`를
`jo="제8조"`/`jo="제9조"`/`jo="000800"`/jo 생략 등 여러 조합으로 직접 호출하였으나 매번
`[NOT_FOUND] 법령 데이터를 찾을 수 없습니다` 오류를 반환하였다. 그러나 같은 MST·같은 조문을
`legal_analysis`(`mode='applicable_law'`, `lawName`='근로자퇴직급여 보장법', `date`='2025-11-30',
`jo`='제8조'|'제9조')로 재조회하면 정확히 MST 279829 버전의 조문 원문(부칙 포함)이 정상 반환되고,
그 내용이 소장의 동결 발췌와 완전히 일치함을 확인했다. 즉 이 사건에서 (a)존재·(b)내용일치는
`get_law_text` 대신 `applicable_law`를 통해 독립적으로 검증되었으며, 인용 자체의 오류가 아니라
`get_law_text`가 이 법령의 해당 연혁 MST를 직접 해석하지 못하는 도구 한계로 판단한다(상세는
별도 회귀 보고서 `.superpowers/sdd/task-7-verify소장-report.md`의 "MCP 재조회 작동 여부" 절 참조).

## 3. 구판(git 대조) 보고와의 차이 — 민법 제379조

2026-06-13자 구판 보고(legalize-kr git 저장소 대조)는 민법 제379조에 대해 기준일 시행 버전에서
"연 **5분**", 현행(HEAD)에서 "연 **5푼**"이라는 자구 차이를 근거로 ⚠️ 판정을 내린 바 있다.
이번 korean-law-mcp 재조회에서는 `get_law_text`(현행, MST 284415)와
`legal_analysis`(`applicable_law`, date=2023-01-01·2025-11-30, jo='제379조') 양쪽 모두
**"연 5푼"으로 완전히 동일**했고 자구 차이가 재현되지 않았다. 국가법령정보센터 Open API(법제처
공식 데이터) 기준으로는 두 시점 모두 "연 5푼"이 맞는 표기이므로, 구판 보고의 "연 5분" 소견은 구
git 미러(legalize-kr)의 데이터 정합성 문제였을 가능성이 높다(현재 해당 저장소 대조 방식은 폐지됨).
이 항목은 korean-law-mcp 기준으로 ✅ 처리하고 ⚠️를 해제한다.
